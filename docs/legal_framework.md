## 4. Regulatory Compliance Checklist

### GDPR Compliance (EU)

| Requirement | How We Address It |
|---|---|
| Lawful basis for processing | User (Data Controller) must determine. Likely basis: legitimate interest or consent |
| Right to access | User must handle DSARs. Reports are delivered as PDF — provide copy on request |
| Right to erasure | Built-in data purge deletes all personal data post-delivery |
| Right to object | User must accept objections from profiled individuals |
| Data minimization | Only public data is collected. Image limit: 5. Time limit: 2 years |
| Data Protection Impact Assessment | User should conduct DPIA before deploying in EU |
| Article 22 (automated decisions) | Reports carry "decision support only" disclaimer |
| Data transfer (international) | User's Apify/Gemini calls may cross borders — User responsibility |

### CCPA Compliance (California)

| Requirement | How We Address It |
|---|---|
| Right to know | Report metadata includes data sources and categories |
| Right to delete | Built-in data purge |
| Right to opt-out | User must provide mechanism for profiled individuals |
| Non-discrimination | Explicitly prohibited in ToS Section 4 |
| Automated decision disclosure | CCPA ADMT pre-use notice required from Jan 2027 |

### EU AI Act Compliance

| Requirement | How We Address It |
|---|---|
| Risk classification | Product is likely "Limited Risk" (profiling without legal effects) |
| Transparency obligation | Every report discloses AI generation + methodology |
| Human oversight requirement | Reports carry "not for sole decision-making" mandate |
| Social scoring prohibition | Explicitly prohibited in ToS Section 4.8 |
| Biometric categorization | Product does NOT categorize by protected characteristics |
